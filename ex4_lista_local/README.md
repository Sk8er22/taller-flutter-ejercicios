# Ejercicio 4 — Lista con datos locales (15 min)

**Abrir en DartPad:** https://dartpad.dev/?id=cbcf9d235ee6e057f1918cb76ed955c1

Crea el proyecto (ver README raíz) y sustituye `lib/main.dart` por `starter.dart`.

1. Ya tienes una lista de 20 nombres.
2. Muéstrala con `ListView.builder` dentro del `Scaffold`.
3. Al tocar una fila, muestra un `SnackBar` con el nombre.

**Extra:** añade un buscador que filtre la lista. Aquí sí necesitarás un `StatefulWidget`.

Guarda tu resultado: es la UI del ejercicio 5.
