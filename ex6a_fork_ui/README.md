# Ejercicio 6a: fork del template, retos de interfaz (15 min)

Base: fork de levin-riegner/flutter-template. Comprueba la licencia antes de publicarlo.

1. `git clone [URL de tu fork]` y `cd flutter-template`.
2. `fvm install`, `flutter pub get`, `flutter pub run build_runner build --delete-conflicting-outputs`.
3. `flutter run -d chrome -t lib/main_qa.dart`.

## Retos
1. Cambia el color del tema.
2. Cambia un texto desde `app_en.arb` (nunca en los archivos generados).
3. Abre un Widget Preview de una pantalla (verifica que tu versión de Flutter lo soporta).

Bonus: cambia el icono principal o añade un botón.

Si el fork no arranca: repite el ejercicio 4 (`ex4_lista_local`).
